# opencti-arm64

as the subject indicates, this is my opencti docker setup. It is essentially a 1-click deployment that is working 100% all debugged based on an 2025 Macbook Pro with M4 chipset. As it is for ARM64 environments, you must adapt it to Intel if you want it to work in your environment. Please pay attention to the <PLEASE CHANGE THIS USING UUIDGEN OR SIMILAR TOOLING> style tags to fill it with your own random values
